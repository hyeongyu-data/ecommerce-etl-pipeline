## 검증 범위 · 2026-09-15

합성·목업 데이터의 기존 E2E 결과입니다. 적재 함수 직접 호출의 대상일 혼입·부분 입력·동시 실행은 추가 검증이 필요하며 합산 금액은 총매출이 아닙니다.

실시간 관제 서비스가 아닌 발표용 화면입니다. 수치는 검증 시점 또는 예시 범위를 따릅니다.
